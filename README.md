# Minimal AI Models

This repository contains **minimal implementations** of several neural network architectures.  
The goal is to illustrate their internal mechanisms in the simplest possible way, rather than to provide production-ready solutions.

- **RNN (Recurrent Neural Network)**  
  A basic sequential model that processes input step by step.  
  This minimal version shows how recurrence works without additional optimizations.

- **GRU (Gated Recurrent Unit)**  
  A simplified recurrent model with gating mechanisms.  
  The minimal design highlights how update and reset gates control information flow.

- **LSTM (Long Short-Term Memory)**  
  A recurrent model capable of handling long-term dependencies.  
  This minimal version demonstrates the core idea of input, output, and forget gates.

- **MLP (Multilayer Perceptron)**  
  A simple feedforward network with fully connected layers.  
  Included here to contrast sequential models with a basic non-recurrent architecture.
